# C8 — Implementation Progress Tracker

Living status of closing audit finding **C8** ("RGB send intent is not independently verified
before signing"). Updated as work lands. Authoritative design lives in the spec/plan; this file is
the at-a-glance state + pointers.

- **Goal (locked):** fully close C8's THEFT / wrong-transfer surface, **nothing else, without exposing
  new issues.** Fix = additive, fail-closed pre-sign gate; on any failure → `FailTransfers`, never
  sign. Worst-case gate bug = false-reject (liveness), never a weaker signature.
- **Trust boundary:** rgb-lib runs in-process and is DISTRUSTED. Crypto verification lives in a
  separate trust domain (new `native/rgb-verify` crate pinning PUBLISHED crates `=0.11.1-rc.10`, no
  rgb-lib dep).
